# تحدي الذكاء الاصطناعي — لعبة اختبار تفاعلية

لعبة أسئلة عربية (RTL) مبنية على منهج **البرمجة والذكاء الاصطناعي** للصف الثاني الثانوي.
كل سؤال مبني على نص درسه هو في الكتاب (الفصل الأول: تكنولوجيا المعلومات والذكاء الاصطناعي،
الفصل الثاني: الأمن السيبراني).

## التشغيل

**الطريقة الأسهل:** افتح ملف `index.html` بالنقر المزدوج — تعمل اللعبة مباشرة في المتصفح بدون إنترنت وبدون أي تثبيت.

**طريقة اختيارية (سيرفر محلي):**

```bash
node serve.js
# ثم افتح: http://localhost:8099
```

## المستويات

في أعلى الشاشة الرئيسية يوجد زرّان لتبديل المستوى، وعدد كل درس يتغيّر حسب المستوى المختار:

| المستوى | الوصف |
|---------|-------|
| **المستوى الأول** | أسئلة الدرس الأساسية (اختيار من متعدد + أسئلة متنوعة) |
| **المستوى الثاني** | أسئلة امتحنانية متقدمة، تركّز على الفهم والتحليل والمقارنة والتطبيق |

## المحتوى

| الدرس | العنوان | المستوى الأول | المستوى الثاني |
|------|---------|---------------|----------------|
| 1-1 | تطور تكنولوجيا المعلومات والتحول الاجتماعي | ٤٦ | ٣٢ |
| 1-2 | كيف يعمل الذكاء الاصطناعي | ٤٠ | ٣٤ |
| 1-3 | الذكاء الاصطناعي في الحياة اليومية والصناعة | ٤٢ | ٤١ |
| 1-4 | القضايا الأخلاقية للذكاء الاصطناعي | ٤٨ | ٣٨ |
| 2-1 | تقنيات التشفير والمصادقة | ٥٠ | ٣٦ |
| 2-2 | تصميم أمن الشبكات | ٥٥ | ٣٧ |
| 2-3 | الاستجابة للحوادث وإدارة المخاطر | ٦٥ | ٣٩ |

**الإجمالي: ٦٠٣ سؤالا** (٣٤٦ في المستوى الأول + ٢٥٧ في المستوى الثاني)، موزعة على خمسة أنواع أسئلة على غرار أسئلة الكتاب:

| النوع | المستوى الأول | المستوى الثاني |
|-------|---------------|----------------|
| اختيار من متعدد | ٢٤٦ | ٢٢٢ |
| صح وخطأ مع التصحيح | ٥٣ | ١٤ |
| أكمل الفراغ | ٣٣ | ٩ |
| رتّب تصاعدا | ٧ | ٥ |
| صنّف | ٧ | ٧ |

## نظام النقاط

| الحدث | النقاط |
|-------|--------|
| إجابة صحيحة | ‎+١٠ |
| إجابة صحيحة ضمن سلسلة ٣ صحيحات فأكثر | ‎×٢ |
| إجابة سريعة (خلال ١٠ ثوان) | ‎+٢٥ بونس |
| إجابة خاطئة أو انتهاء الوقت | ‎−٥ |
| مراجعة الخطأ في نهاية الامتحان | موبة |

- مؤقّت ٣٠ ثانية لكل سؤال، وشريط يوضّح الوقت المتبقي.
- عند الإجابة الخطأ تُظهر اللعبة **الإجابة الصحيحة فورا**.
- في نهاية الامتحان: النسبة والنجوم، أطول سلسلة، عدد الإجابات السريعة، وقائمة مراجعة لكل سؤال أخطأت فيه.
- **لا يتم حفظ النتيجة** بعد انتهاء الدرس.

## طريقة اللعب

1. اختر المستوى (الأول أو الثاني) من الأزرار أعلى الشاشة.
2. اختر درسا من البطاقات — تُقدَّم **كل** أسئلة الدرس في المستوى المختار — أو اضغط **الامتحان الشامل** (٣٠ سؤالا عشوائية من كل دروس المستوى الحالي).
3. أجب بالنقر على الخيار، أو بمفاتيح لوحة المفاتيح `1` `2` `3` `4`.
4. بعد الإجابة يظهر التصحيح، ثم اضغط **التالي** (أو `Enter`).

## ملاحظات

- كل سؤال ينتمي إلى درسه فقط: لا يوجد خلط بين الدروس، ولا بين المستويين.
- لا تحتاج اللعبة إلى أي مكتبة خارجية أو اتصال بالإنترنت.
- لإضافة أسئلة جديدة: أضف عنصرا جديدا داخل `questions` في ملف الدرس المطلوب
  بالشكل `{ q: 'نص السؤال', o: ['خيار', 'خيار', 'خيار', 'خيار'], a: 0 }`
  حيث `a` هو رقم الخيار الصحيح (يبدأ من ٠).
- تلميحات الألوان: أخضر = إجابة صحيحة، أحمر = إجابة خاطئة.
