# تحدي الذكاء الاصطناعي — لعبة اختبار تفاعلية

لعبة أسئلة عربية (RTL) مبنية على منهج **البرمجة والذكاء الاصطناعي** للصف الثاني الثانوي — الفصول الأربعة كاملة:
الفصل الأول (تكنولوجيا المعلومات والذكاء الاصطناعي)، الفصل الثاني (الأمن السيبراني)، الفصل الثالث (تطبيقات الويب)، الفصل الرابع (تصميم الويب والوسائط).
كل سؤال وملخص مبني على نص درسه في الكتاب وتمت مراجعته درسا درسا مقابل الكتاب.

## التشغيل

**الطريقة الأسهل:** افتح ملف `index.html` بالنقر المزدوج — تعمل اللعبة مباشرة في المتصفح بدون إنترنت وبدون أي تثبيت (تقرأ نسخة المحتوى المدمجة `content-bundle.js`).

**طريقة اختيارية (سيرفر محلي):**

```bash
node serve.js
# ثم افتح: http://localhost:8099
```

## نظام النقاط

| الحدث | النقاط |
|-------|--------|
| إجابة صحيحة | ‎+١٠ |
| إجابة صحيحة ضمن سلسلة ٣ صحيحات فأكثر | ‎×٢ |
| إجابة سريعة (خلال ١٠ ثوان) | ‎+٢٥ بونس |
| إجابة خاطئة أو انتهاء الوقت | ‎−٥ |
| مراجعة الخطأ في نهاية الامتحان | مجانا |

- مؤقّت ٣٠ ثانية لكل سؤال، وشريط يوضّح الوقت المتبقي.
- عند الإجابة الخطأ تُظهر اللعبة **الإجابة الصحيحة فورا**.
- في نهاية الامتحان: النسبة والنجوم، أطول سلسلة، عدد الإجابات السريعة، وقائمة مراجعة لكل سؤال أخطأت فيه.
- **لا يتم حفظ النتيجة** بعد انتهاء الدرس.
- الامتحان الشامل: أسئلة عشوائية من كل دروس المستوى الحالي، مع امتحانات الفصول الأربعة، وامتحانين نهائيين عامين يغطيان كل أسئلة الفصول الأربعة (واحد لكل مستوى).

## طريقة اللعب

1. اختر المستوى (الأول أو الثاني) من الأزرار أعلى الشاشة.
2. اختر درسا من البطاقات — تُقدَّم **كل** أسئلة الدرس في المستوى المختار — أو اضغط **الامتحان الشامل** أو امتحان فصل أو **الامتحان العام النهائي**.
3. أجب بالنقر على الخيار، أو بمفاتيح لوحة المفاتيح `1` `2` `3` `4`.
4. بعد الإجابة يظهر التصحيح، ثم اضغط **التالي** (أو `Enter`).

## الملفات

```
index.html          هيكل الواجهة (شاشات البداية والسؤال والنتيجة + أزرار المستوى)
style.css           التنسيقات (تصميم ليلي متوهج + تبويبات المستوى + استجابة للشاشات)
app.js              منطق اللعبة: العرض، المؤقت، النقاط، المستويات، المؤثرات
content-loader.js   يحمل content/*.json عبر fetch، ويرجع تلقائيا إلى content-bundle.js عند file://
content-bundle.js   نسخة مولّدة تلقائيا من content/*.json (للعمل بدون سيرفر) — لا تعدلها يدويا
content/*.json      المصدر الوحيد للمحتوى (الدرس والأسئلة والملخصات والفصول والعدادات) — عدّل هنا
build-bundle.js     يعيد توليد content-bundle.js من content/*.json (node build-bundle.js)
verify-content.js   فاحص صحة المحتوى: البنية + تطابق العدادات مع manifest + تطابق الحزمة (node verify-content.js)
serve.js            سيرفر محلي اختياري
data-*.js, data2-*.js, summaries.js, lesson-extras.js   ملفات قديمة لم يعد التطبيق يستخدمها (مرجع تاريخي فقط — لا تعدلها ولا تعتمد عليها)
```

## ملاحظات

- **content/*.json هو المصدر**: أي تعديل على الأسئلة أو الملخصات يكون هنا، ثم `node build-bundle.js` ثم `node verify-content.js`. لا تعدل `content-bundle.js` يدويا.
- سكربت `build-content.js` القديم (الذي كان يولّد الـ JSON من الملفات القديمة) أُزيل؛ تشغيله الآن يتحقق من صحة المحتوى فقط حتى لا يُستبدل محتوى معدّل ببيانات قديمة.
- كل سؤال ينتمي إلى درسه فقط: لا يوجد خلط بين الدروس، ولا بين المستويين.
- خيارات اختيار من متعدد تُخزَّن دائما بحيث تكون الإجابة الصحيحة أول خيار (`a: 0`) — اللعبة تخلط الخيارات وقت العرض، فلا يظهر النمط للطالب.
- لإضافة سؤال جديد: أضف عنصرا داخل `questions` في الدرس المطلوب بالشكل
  `{ "q": "نص السؤال", "o": ["الإجابة الصحيحة", "خيار", "خيار", "خيار"], "a": 0, "fix": "سبب صحة الإجابة" }`.
- الأسئلة المتنوعة: صح/خطأ (`t: "tf"` مع `a` منطقية و`fix` للتصحيح)، أكمل الفراغ (`t: "fill"` مع `ans` لكل الإجابات المقبولة)، ترتيب (`t: "order"` مع `items` بالترتيب الصحيح نفسه)، تصنيف (`t: "classify"` مع `groups`).
- تلميحات الألوان: أخضر = إجابة صحيحة، أحمر = إجابة خاطئة.
